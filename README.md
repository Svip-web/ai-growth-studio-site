## Редагування та перевірка

Сайт не потребує встановлення залежностей або серверного збирання.

- `index.html` — розмітка.
- `assets/site.css` — стилі й локальні шрифти.
- `assets/site.js` — поведінка та дані карток.
- `assets/media/` — адаптивні WebP-зображення; однакові оригінали використовують спільні файли.
- `assets/image-manifest.json` — відповідність оригіналів адаптивним зображенням.
- `assets/fonts/` — локальні WOFF2 та ліцензії OFL.

Після змін запустіть `npm run build`, потім `npm test`. Скрипти використовують лише Node.js: перевіряють посилання, розміри зображень, синтаксис JavaScript, бюджети ресурсів і оновлюють версії CSS/JS для кешування.

Оптимізація не видаляє початкові зображення. Нові оригінали й чернетки зберігаються локально; для публікації достатньо оптимізованих файлів. Браузер завантажує WebP потрібної ширини; закриті послуги не завантажують фото до відкриття. Анімації призупиняються поза екраном і в неактивній вкладці; налаштування зменшення руху враховано. Виміряні результати — у `PERFORMANCE.md`.
